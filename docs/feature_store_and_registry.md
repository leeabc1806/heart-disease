# 피처 스토어 & 모델 레지스트리 — 논리 설명

## 피처 스토어에 등록해야 할 피처: `oldpeak` (ST 하강)

**이유**: `oldpeak`는 운동 유발 ST 하강값으로, 심장 허혈의 핵심 임상 지표다.
EDA에서 타깃과 관련성이 관찰됐으며, 현재 RandomForest 특성 선택에서도
채택된 피처다. 여러 모델·실험에서 반복 사용될 가능성이 있으므로
Feast 등 피처 스토어에 등록해두면 재사용성과 일관성이 보장된다.
또한 실시간 임상 시스템에서는 ECG 장비에서 자동으로 측정·업데이트되는 값이므로,
피처 스토어가 최신성(freshness) 관리를 담당해야 한다.

## 모델 레지스트리에 기록해야 할 메타데이터: `recall` 값

**이유**: 이 시스템의 핵심 안전 지표는 recall(심장병 환자를 놓치지 않는 비율)이다.
MLflow Registry에 모델 버전을 등록할 때 recall을 필수 메타데이터로 기록하면,
배포 전 검토 시 "현재 배포 모델보다 recall이 낮은 버전은 Production으로 승격 불가"
같은 게이팅 규칙을 자동화할 수 있다. 이는 Human-in-the-loop 안전망의
핵심 데이터 포인트 역할을 한다.
